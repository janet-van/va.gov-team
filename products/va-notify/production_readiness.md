## Production Readiness Checklist

Before sending notifications in production, follow this sequence:

1. Service is onboarded and active in Staging* (required)
2. Business, Technical Contacts and Editors are assigned* (required)
3. Create notification template(s)* (required)
4. Business Contact reviews and approves content* (required)
5. Privacy Officer reviews and approves content* (required)
6. Obtain staging API key from VA Notify* (required)
7. Implement triggering event in your system* (required)
8. Integrate with VA Notify using Staging API key* (required)
9. Run end-to-end testing in Staging
10. Verify all personalization fields
11. Obtain Production API key from VA Notify* (required)
12. Integrate Production API key into your system* (required)
13. Send test notification(s) in Production* (required)
14. Configure callbacks* (required)
15. Ensure your system can receive and process delivery status updates
16. Set up monitoring and/or logging
